# Jobs, Property, and Photos

## REQ-WORKFLOW-001 Create an appraisal job

An appraiser can create a job with a job number, inspection date, client, and destination bank. The initial form shows draft status; the job number and date remain editable while the job is a draft.

## REQ-WORKFLOW-002 Save a job

Edits autosave locally, with a manual Save action. Reloading in the same browser restores the latest data. Starting a new job requires confirmation before clearing current data.

## REQ-PROPERTY-001 Record the home and location

Store a text address, latitude, longitude, property type and condition, land and usable area, floor count, construction year, bedroom and bathroom counts, and additional details.

## REQ-PROPERTY-002 Show units

Display the exact UI units `ตร.วา`, `ตร.ม.`, and `บาท`. Store numeric values without thousands separators.

## REQ-PHOTO-001 Add evidence photos

An appraiser can add multiple device images and preview them before printing the report.

## REQ-PHOTO-002 Remove evidence photos

An appraiser can remove selected images before saving or printing; removed images must not appear in the report.
