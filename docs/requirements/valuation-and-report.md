# Valuation and Report

For price-reference evidence and its limitations, read [references.md](references.md).

## REQ-VALUATION-001 Choose a valuation method

Support three methods: manual amount, usable area multiplied by price per square meter, and an entered comparable-property amount.

## REQ-VALUATION-002 Explain the result

Show the valuation amount and the selected calculation method so reviewers can understand its origin.

## REQ-REPORT-001 Print the report

An appraiser can print the job or save it as PDF through the browser print dialog. The report includes property details and photos.

## REQ-REPORT-002 State the bank-delivery limitation

The prototype must say that it has not delivered data to a bank; actual delivery requires an approved bank API or form contract.
